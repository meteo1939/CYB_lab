# CYB_lab

Zadania z bezpieczeństwa aplikacji — wariant 8.

| Folder | Moduł | Opis |
| --- | --- | --- |
| [`lab1`](lab1/) | Identyfikacja, uwierzytelnianie, autoryzacja | Portal KLUCZ: Argon2id, RBAC, sesje, TOTP |
| [`lab2`](lab2/) | Ochrona logowania | Limity prób, reCAPTCHA, honeypot, Canarytokens, test bota |

Każdy folder ma własny `package.json`. Uruchamiaj osobno:

```bash
cd lab1
npm install
npm start
```

```bash
cd lab2
npm install
npm start
```
